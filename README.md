# Творческая мастерская Людмилы Зюлиной

Сайт мастер-классов по рукоделию: онлайн, офлайн, видео в записи, инструкции с картинками, работы на заказ.
Код живёт здесь, превью — на GitHub Pages, рабочий сайт — в Тильде.

## Что где лежит

| Папка / файл | Что это |
|---|---|
| `src/base.html` | Цвета, шрифты, кнопки, метки форматов, декор. Общий для всех страниц |
| `src/sections/*.html` | Секции. Каждая со своими стилями, все классы начинаются с `.zm-`, чтобы не конфликтовать с Тильдой |
| `src/pages.json` | Из каких секций собрана каждая страница |
| `assets/` | Шрифты (OFL 1.1), декор, временные картинки-заглушки |
| `docs/` | **Собранное превью** для GitHub Pages (не править руками) |
| `tilda/<страница>/` | **Готовые блоки для Тильды**, пронумерованы по порядку вставки |
| `tilda/SIZES.txt` | Размер каждого блока. Лимит блока T123 — 25 000 байт |

## Как пересобрать и проверить

```bash
python3 tools/make_assets.py   # только если меняли заглушки или логотип-генератор
python3 build.py               # собирает docs/ и tilda/
python3 verify.py --shots      # проверки + скриншоты в shots/
```

`verify.py` проверяет: размер блоков, изоляцию стилей, битые ссылки и картинки, отсутствие ошибок JS,
отсутствие горизонтальной прокрутки на 1440 и 375 px, работу бургер-меню, фильтра каталога и подстановки
выбранного мастер-класса на странице контактов.

## Что заменить до запуска

Всё временное помечено классом `zm-todo`: на превью GitHub оно обведено красным пунктиром, в блоках
для Тильды пунктир отключён. Найти все места: поиск `zm-todo` по папке `src/`.

- фото и видео-обложки в `assets/img/` (сохранить те же имена файлов — тогда код менять не нужно);
- цены, возраст, длительность мастер-классов;
- ссылки на Telegram, WhatsApp, ВКонтакте, телефон, e-mail;
- отзывы — только реальные, с разрешения авторов;
- текст политики обработки персональных данных;
- логотип `assets/decor/logo.svg` — экспорт из Figma с текстом в кривых.

## Перенос в Тильду: пошагово

Картинки и шрифты в блоках Тильды подгружаются с GitHub Pages
(адрес в `site.config.json`, поле `tilda_asset_base`). Поэтому сначала должен заработать GitHub Pages.

### 1. Настроить проект в Тильде (один раз)

1. Откройте tilda.cc → **Мои сайты** → **Создать новый сайт**, назовите его.
2. **Настройки сайта** → вкладка **Шрифты и цвета** → цвет фона `#F8F5F0`.
3. **Настройки сайта** → **Ещё** → поле **HTML-код для вставки внутрь HEAD** оставьте пустым:
   шрифты уже подключаются в первом блоке каждой страницы.

### 2. Создать страницы

Создайте 7 страниц. В **Настройках страницы** → **Адрес страницы** укажите адрес строго как в таблице,
иначе ссылки меню не сработают:

| Страница в коде | Название | Адрес в Тильде |
|---|---|---|
| `index` | Главная | (сделать главной: Настройки сайта → Главная страница) |
| `workshops` | Мастер-классы | `workshops` |
| `works` | Работы на заказ | `works` |
| `about` | Обо мне | `about` |
| `blog` | Блог | `blog` |
| `contacts` | Контакты | `contacts` |
| `privacy` | Политика | `privacy` |

Заголовок и описание для поиска возьмите из `src/pages.json` (поля `title` и `description`):
**Настройки страницы** → **Главное** → **Заголовок**, **Описание**.

### 3. Вставить блоки

Для каждой страницы, по порядку файлов в `tilda/<страница>/` (00, 01, 02…):

1. На странице нажмите **Все блоки** (или «+» между блоками) → категория **Другое** → блок **T123 HTML-код**.
2. Нажмите **Контент** у этого блока, откройте нужный файл (например, `tilda/index/00-base.html`),
   скопируйте **всё** содержимое и вставьте в поле. Нажмите **Сохранить и закрыть**.
3. Нажмите **Настройки** блока → **Отступ сверху** = 0, **Отступ снизу** = 0 → **Сохранить**.
4. Повторите для следующего файла, добавляя блок ниже предыдущего.

Первый блок каждой страницы — всегда `00-base.html`. Без него остальные блоки останутся без цветов и шрифтов.

> В редакторе Тильды HTML-блоки показываются серыми заглушками. Это нормально:
> смотреть результат нужно через **Предпросмотр** или после **Опубликовать**.

### 4. Заменить два блока на родные блоки Тильды

- **Форма заявки** на странице `contacts`: под блоком `02-contacts` добавьте стандартную форму
  (категория **Форма**, например BF203N). Подключите получение заявок:
  **Настройки сайта** → **Формы** → выберите e-mail или Telegram. Включите галочку согласия
  на обработку данных со ссылкой на `/privacy`.
- **Блог**: чтобы Людмила добавляла посты сама, соберите страницу `blog` на **Потоках**
  (**Настройки сайта** → **Потоки** → **Создать поток**), а на страницу поставьте блок из категории
  **Потоки**. Блок `02-blog-list` тогда удалите. Карточку блога на главной (`08-blog-rail`) можно оставить
  или тоже заменить потоком.

### 5. Опубликовать и проверить

**Опубликовать все страницы** → открыть сайт на телефоне и компьютере, проверить меню, фильтр
мастер-классов (кнопки «Онлайн», «Инструкция»…), кнопки «Записаться».

## Когда меняется контент

Правите файл в `src/` → `python3 build.py` → `python3 verify.py` → коммит и пуш в GitHub
→ в Тильде открываете соответствующий блок T123 и заменяете его содержимое новым файлом из `tilda/`.
Картинки, лежащие на GitHub Pages, обновятся на сайте сами, без правки Тильды.
